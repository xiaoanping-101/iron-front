# 钢铁前线 · IRON FRONT

原创横版射击闯关游戏：六张地图、步兵、无人机、装甲 Boss、跳跃平台、重机枪补给、手雷、音效与本地最高分。浏览器运行，支持键盘和触屏。

## 开始游戏

[直接在线游玩](https://xiaoanping-101.github.io/iron-front/)

下载仓库 ZIP，解压后双击 `index.html` 即可离线游玩。也可以安装 Node.js 后运行 `npm start`，打开 http://127.0.0.1:4173 。运行游戏无需安装 npm 依赖。

| 操作 | 按键 |
| --- | --- |
| 移动 | A / D 或左右方向键 |
| 前后路线 | Q 后移 / E 前移（站稳后切换） |
| 跳跃 / 从桥面下落 | 空格 / S + 空格 |
| 连续射击 | 长按 J |
| 朝上瞄准 | W 或上方向键 |
| 换弹 | R（1.5 秒，期间不能射击） |
| 手雷 | K（投掷冷却 0.75 秒） |
| 暂停 / 继续 | P / Esc |
| 开始 / 下一关 | Enter |

触屏设备提供屏幕按钮，建议横屏。全屏模式主要供键盘使用；触屏按钮位于普通页面游戏下方。

每关击败装甲 Boss 后进入下一关。黄色 H 补给提供限时重机枪和 30 发备弹，绿色 + 恢复两格生命。蓝色 A 补给提供 90 发备弹与 2 枚手雷。手雷同时清除附近敌方弹幕。每关重置生命、30 发弹匣、150 发备弹和 3 枚手雷；失败后重新开始六关战役。

## 开发与验证

`npm install` 安装仅供测试使用的 Playwright；`npm test` 使用本机 Chrome 做运行检查。可通过 `BROWSER_PATH` 指定 Chromium 可执行文件。测试截图保存在 `test-results/`，不提交仓库。

这是完整可玩的轻量街机原型，采用程序绘制的像素美术，目标是短流程单人闯关；不包含多人模式或商业级动画素材。

## v1.1 战役与弹药规则

六关依次为：边境废墟、赤沙工厂、极夜要塞、雨林封锁、冰原列车、熔炉核心。关卡具有不同长度、平台间距、敌人密度和环境效果；后三关 Boss 使用五向弹幕与移动炮塔。

- 弹匣 30 发，初始备弹 150 发，备弹上限 240 发。每次射击消耗 1 发；重机枪的三向弹丸消耗同一次射击的 1 发。
- R 主动换弹；空弹匣尝试射击时自动换弹。换弹 1.5 秒，可移动、跳跃或投掷手雷，但不能射击。满弹匣或零备弹不能换弹。暂停会冻结换弹计时。
- 换弹保留弹匣余弹，只从备弹补足缺额；备弹不足时按实际数量装填。
- 手雷每关 3 枚、携带上限 5 枚；每次按 K 投掷 1 枚，冷却 0.75 秒，耗尽后无法投掷。
- 程序像素画升级：建筑纹理、破损电线、装备细节、装甲铆钉、植被、雪山列车、雨雪粒子、火星和环境光。

## v1.2 立体地图与渲染

- 六关均改为前、中、后三条实际可切换的 2.5D 路线。不同路线有不同坡度，栈道和高地设有单向桥面与额外补给。Q / E 切换路线，有短暂冷却，空中不能切换；从桥面切换会落到目标路线地面。
- 角色与步兵沿坡面移动；空格跳上桥面，S + 空格穿过桥面下落。镜头平滑跟随水平与高度变化。
- 普通子弹、手雷、敌人接触和补给按路线判定；Boss 占据全线装甲区域，可从各路线攻击，Boss 会向玩家当前路线开火。
- 多层视差背景、带顶面和侧面的道路与建筑、角色接地阴影、远近遮挡和缓存环境光。
- 两张离屏背景图、640 像素地形分块、最多 12 块 LRU 缓存；只绘制可见区域，粒子最多 220 个。原有背景重复绘制与逐帧渐变创建已移除。
- 同机无界面 Chrome 固定场景测试：200 次滚动绘制中，矩形绘制调用由约 704 次/帧降低到约 162 次/帧。该指标衡量绘制工作量，不代表实际设备 FPS；耗时结果保存在本地测试输出中。
