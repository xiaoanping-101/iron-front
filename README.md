# 钢铁前线 · IRON FRONT

六关单人街机射击游戏。v1.4 保留 **WASD 连续自由移动的一体地图**：玩家、步兵、无人机和 Boss 共用相同的地面坐标，不再有固定路线、换线按键或选路界面。

[直接在线游玩](https://xiaoanping-101.github.io/iron-front/?v=1.4)

## 操作

| 操作 | 按键 |
| --- | --- |
| 自由移动 | WASD 或方向键；支持斜向，斜向不加速 |
| 跳跃 | 空格；支持短暂输入缓冲，可跳上低掩体 |
| 冲刺 | Shift + 移动；短距离加速，有冷却，无无敌效果 |
| 射击 | 长按 J，沿最后移动方向射击 |
| 换弹 | R；耗时 1.5 秒，期间无法射击 |
| 手雷 | K；沿当前朝向投掷 |
| 暂停 / 继续 | P / Esc |
| 开始 / 下一关 | Enter |

移动带短促加速与制动，斜向速度归一化；冲刺不能穿过高掩体。

W/S 是地面前后移动，不是朝空中瞄准。Q/E 选路和 S+空格穿桥操作已取消。触屏提供四方向移动、跳跃、射击、换弹和手雷按钮，建议横屏。全屏按钮主要适用于键盘，触屏控制位于正常页面游戏下方。

## 连续地图与敌人

- 连续地面保留缓坡、场景纵深和脚下阴影。新增木箱、低路障和集装箱，角色与掩体按实际前后位置排序绘制。低矮掩体可跳上或越过，子弹会被掩体挡住。
- 步兵从不同位置追近玩家，在射程内侧移；共享导航网格与距离场让步兵绕开掩体，无人机从上方通过。Boss 也会调整前后位置。六张地图均测试出生区与 Boss 区的地面连通性。
- 子弹根据位置、纵深距离和高度判定命中，敌人瞄准玩家当前所在位置。手雷在实际落点产生圆形范围伤害，并清除附近敌方弹幕。
- 前进抵达 Boss 区域后封锁回退，消灭 Boss 进入下一关。六关为边境废墟、赤沙工厂、极夜要塞、雨林封锁、冰原列车、熔炉核心。

## 弹药与补给

- 弹匣 30 发，初始备弹 150 发，备弹上限 240 发。空弹匣尝试射击时自动换弹。
- 换弹保留余弹，仅消耗补足缺额所需备弹。满弹匣或零备弹不能换弹；暂停冻结换弹计时。
- 每关 3 枚手雷，最多携带 5 枚，投掷冷却 0.75 秒。
- 黄色 H：限时重机枪与 30 发备弹；绿色 +：两格生命；蓝色 A：90 发备弹与 2 枚手雷。
- 每关恢复生命、弹匣、150 发备弹与 3 枚手雷。失败后重新开始六关战役。最高分存于本机浏览器。

## 本地运行与测试

下载 ZIP 解压后双击 `index.html` 即可离线游玩，无运行时 CDN 请求。也可安装 Node.js 后运行 `npm start`，访问 http://127.0.0.1:4173 。

`npm install` 安装仅用于测试的 Playwright，`npm test` 使用本机 Chrome；可通过 `BROWSER_PATH` 指定 Chromium 路径。测试覆盖 WASD/斜向移动、跳跃、连续边界、敌人追击侧移、方向射击、空间碰撞、手雷、换弹、六关衔接和移动端。截图在 `test-results/`，不提交仓库。

渲染保留两张离屏背景、640 像素地形分块、最多 8 块 LRU 缓存、视野裁剪与 220 个粒子上限。地图模型已重构，旧版三路线渲染的性能测量不作为当前版本 FPS 声明。

## v1.4 美术与渲染

- 六种场景色调、可见建筑与远景吊机、雨林植被、雪山列车、夜间发光窗；重绘地面材质、裂缝、积水、格栅与进度箭头。
- 64 张预绘制角色动画帧覆盖敌我、步行动画和八方向朝向；立体补给箱、软阴影、枪口闪光、弹道拖尾与爆炸冲击环。
- 静态细节烘焙进地形分块；重用绘制列表，取消逐个粒子的上下文保存恢复，镜头坐标对齐像素以减少抖动。保留 8 块地形缓存、220 粒子与 12 个爆炸效果上限。
- 顶部可切换“精细 / 流畅”：流畅模式减少天气和粒子显示、关闭额外光效，碰撞与战斗规则不变。

### 渲染基准

运行 `npm run benchmark`。同机无界面 Chrome，24 名可见步兵，预热 50 次后进行 180 次滚动绘制：主画布 API 调用约从 1070 次/帧降至 119 次/帧；本次测量平均 JS 绘制耗时约从 0.51 ms 降至 0.17 ms。该测试测量命令提交开销，不包含全部 GPU 合成成本，不作为实际设备 FPS 保证。原始报告输出到 `test-results/`。
